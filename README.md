# Cotizador Anestesia Segura

App web (instalable en el teléfono) del **Dr. Julio Barroso – Médico Anestesiólogo**.

- Cotizador de péptidos GLP-1 (Tirzepatida, Semaglutida, Liraglutida) con exámenes de protocolo.
- Cotizador de servicios de anestesia con precio por ítem.
- Genera PDF con logo, método de pago y términos y condiciones.
- Registros guardados en el teléfono.

Precios, servicios, exámenes y términos se editan en `js/config.js`.

Probar en la PC: `npm start` y abrir http://localhost:3000
